设备截图
对受控设备各截一张 PNG（adb exec-out screencap）。
  • 文件名形如 screenshot_<序列号>_<时间>.png，多台设备各存一张。
  • 走后台 adb 直接取帧，不会打断设备当前操作。
  • 勾选「同步至粘贴板」时只复制第一张——剪贴板一次只能放一张（图片仍全部存盘），可直接到微信 / QQ / 文档里 Ctrl+V。
  • 开关与保存目录都记在 config.json，下次启动沿用。
设备录屏
对受控设备各录一段 MP4（adb screenrecord）。需要复盘时勾上「同步录制 logcat」——日志按全量抓取，不截断也不过滤。
logcat 走落盘抓取：全部缓冲区（main / system / events / crash / radio …）＋ 全部级别（V/D/I/W/E/F），不做任何过滤与截断，结束录制时随视频一并打包（若勾选压缩）。指针位置 / 触摸圆点为设备系统 overlay（settings put system pointer_location / show_touches），停止录屏时自动恢复设备原设置。

功能概览

  • 设备指令：多设备批量下发快捷命令（按标签分组）与自定义命令； adb / scrcpy 自动按受控设备拼接 -s，彻底告别 more than one device。
  • 工具：竖向排列的三张卡（截图 / 录屏 / 投屏），每张标题栏单击可收起。批量截图（screencap，可同步至系统粘贴板）、录屏（screenrecord；「同步录制 logcat」按全量抓取、不截断不过滤，「结束自动压缩为 zip」默认开启）、 投屏（一键调用本机已安装的 scrcpy，自动探测路径，一台设备一个窗口）。保存目录由 工具 / Logcat / 文件 三页共享同一设置。
  • 性能监控：类 PerfDog 的实时面板——CPU / 整机内存 / 应用 PSS / 帧率 / 电量 / 电池温度 六项指标实时曲线（点指标卡切换），一键导出 HTML 报告 + CSV（含统计与采样明细）。 数据全部来自设备自带的 /proc 与 dumpsys，不注入、不装 APK、不需 root。单设备。
  • Logcat：实时日志监控——关键字 / 级别 / 缓冲区 / 仅异常 过滤、异常高亮、行数异常计数； 另含抓取模式（落盘 txt，「结束后打包 zip」默认开启）。单设备，随左侧受控设备自动联动。
  • 文件：类 Device Explorer 的远程文件管理——浏览 / 上传 / 下载 / 删除 / 重命名 / 新建 / 查看内容。 单设备，随左侧受控设备自动联动。
  • 全局共享：左侧设备栏跨 tab 常驻可见；顶栏右上角「状态信息」跑马灯跨 tab 常驻，滚动显示最新的刷新 / 执行 / 停止等运行状态，鼠标悬停可暂停细看，点击即弹出完整历史（可复制 / 清空）。
  • 受控设备：左侧勾选即「受控设备」——多设备功能（指令 / 工具）对其广播； 单设备功能（Logcat / 文件）自动以第一个受控设备为当前目标。

本程序为 Web 版（pywebview + backend/* + core/*），逻辑层可单测、可复用。
